## 🚀 Getting Started

### Python Calculator

```bash
cd python-calculator
pip install -r requirements.txt
python calculator.py
python -m pytest tests/
```

### Node.js API Server

```bash
cd nodejs-api
npm install
npm start
npm test
```

### Java Application

```bash
cd java-app
mvn clean install
mvn exec:java
```
